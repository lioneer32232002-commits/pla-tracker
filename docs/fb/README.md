# 粉專 Reels 產線 — 技術文件

本專案在粉專計畫裡只負責一件事：**把 `data/records.csv` 的每日數據，
變成可以直接上傳的每日圖卡與 Reels。**

粉專本身的事情（資格進度、發文節奏、名稱與 banner 決策、貼文改寫規範）
不在這裡，在 `skyfaring/docs/fb/README.md`。會變動的資格數據只寫在那邊，
這份不重複記，避免兩邊對不上。

---

## 1. 這條線要產出什麼

| 產出 | 規格 | 用途 |
|---|---|---|
| 每日 Reel | 9:16（1080×1920），8–12 秒 MP4 | 衝 Reel 段數與不重複瀏覽 |
| 每日貼文配圖 | 4:5（1080×1350）PNG | 搭配文字貼文 |
| 貼文文案 | 純文字，含當日對照句 | 同上 |

**影片不需要做長。** FB 內容營利算的是不重複瀏覽次數，不是觀看分鐘，
8 到 12 秒的高完看率短片比 60 秒更有利。

**每天要有一句只有當天成立的對照**（比近 7 日平均多幾架、逾越中線比例是近
30 日最高等），全部能從 `records.csv` 直接算出來。純數字播報的模板化內容在
Meta 的審核上不佔優勢，對照句是解方。

## 2. 視覺路線：程式繪製（選定）

原型：`scripts/prototype_map_card.py`，輸出 1080×1920 PNG。

- 地圖用 `data/geo_card.json` 的真實經緯度多邊形直接投影，不用任何圖片
- 圖示是程式畫的向量形狀，數量嚴格對應 CSV
- 共機總數 → 圖示總數，機頭一律朝東
- `median_line_cross` 那些用警示色，放在戴維斯線以東到台灣西岸之間；
  其餘放在中國海岸線到中線之間
- 共艦數 → 船形圖示，散布海峽與台灣東部海域
- 中線用真實戴維斯線（北緯 27 度東經 122 度 到 北緯 23 度東經 118 度）
- 圖示大小依當天數量自動縮放
- 放置以日期為亂數種子，同一天重跑結果一致
- 已修正圖示被畫布邊緣切掉的問題（`LON_VIS_LO` / `LON_VIS_HI` 夾範圍），
  否則畫面上的數量會對不上

樣本：
`docs/fb/prototype/map_card_light.png`（2026.8.1-2，5／3／10）、
`docs/fb/prototype/map_card_busy.png`（2026.2.12-13，42／32／11）。

選這條的理由：不需要任何第三方素材，授權問題消失；圖示位置程式化生成；
動畫可用 ffmpeg 完全控制；可完全自動化。

**渲染只在本機跑，不進 CI**（鐵律第 7 條，CI 無中文字型）。ffmpeg 本機已安裝。

## 3. 使用者對原型的評語：整體 60 分

三項待修，優先處理：

1. **重點區域侵擾沒有要的幾何疊加感。**
   目前是同心橢圓外框（六圈、透明度遞減），被評為不足。
   使用者原話是「侵擾區域用等高線的幾何圖形重複疊加」。
   可能方向：層數更多更密、改多邊形而非橢圓、多個中心互相疊加、
   半透明填色堆疊出層次。**動工前先問清楚要的是哪一種。**

2. **數據顯示太醜，沒有軍事感。**
   目前是置中的粗黑體中文，太像一般資訊圖。
   可沿用的既有語彙：`scripts/make_og_image.py` 裡已經有
   `UNCLASSIFIED // OPEN SOURCE · TAIWAN STRAIT` 這類標籤與十字準星圖形。
   方向：等寬字、拉丁字大寫標籤、格線與刻度、數值靠左對齊配標籤欄位。

3. **有些船艦壓在台灣地圖上。**
   放置時只做了圖示之間的間距檢查，沒有做陸地遮罩。
   要加「點是否落在陸地多邊形內」的判斷。

動畫版還沒做。靜態版修到滿意再做，作法是 ffmpeg 疊幀：圖示緩慢東移、
等高線一圈圈往外擴散、數字 count-up。

## 4. 資料限制

`records.csv` 欄位：
`date, aircraft_total, median_line_cross, cross_rate, aircraft_type,
ships_total, activity_start, activity_end, special_event`

`aircraft_type` ∈ Manned／UAV／Mixed／Zero／Helicopter。
原型已支援 UAV 時換成細長翼圖示。

**沒有空域分布欄位**（西南／北部／東部）。目前圖卡的位置分布是示意，
只有數量是準的。使用者已接受這個前提，原話：
「如果沒有太細節的移動情報的話，就是做個示意，數量要對」。

若要讓空域也對得上，得擴 CSV 欄位並改 `fetch_and_update.py` 的圖片辨識。
這是另一件工程，動工前要確認。
